## 修复：婚礼页地图导航按钮（高德/百度）手机端无法选中地址

- 原因：原高德链接带 `city=440300`（深圳市 adcode），但婚礼场地在江西九江修水，导致高德在深圳范围内搜不到「修水县修江国际大酒店」；百度链接用的是桌面端会话残留坐标。
- 修复：两个按钮改用精确坐标点 URL（腾讯地图 GCJ-02 经纬度 114.575731, 29.024183）：
  - 高德：`uri.amap.com/marker?position=114.575731,29.024183&name=修江国际大酒店&coordinate=gaode&callnative=1`
  - 百度：`api.map.baidu.com/marker?location=29.024183,114.575731&title=修江国际大酒店&content=...&output=html&coord_type=gcj02`（百度用 BD-09，传 gcj02 由接口转换）
- 场地：修水修江国际大酒店，江西省九江市修水县宁红大道99-2号，电话 0792-7762777。
- 部署：用户自行把构建产物上传到 EdgeOne，AI 不代劳；改完需用户重新上传/部署生效。

## 站点整体复查（index.html 全量）

### ⚠️ 致命：GitHub PAT 明文暴露在客户端 JS（约第1860行）
- `GITHUB_TOKEN = 'github_pat_...'` 直接写在前端脚本，任何人查看源码即可拿到，且具备 issues 读写权限（祝福提交/管理员删除都用它）。
- 管理员删除仅靠 URL 参数 `?isadmin=true` + 同一公开 token，等于人人可删祝福。
- 必须：立即在 GitHub 吊销该 token；祝福/问卷改走服务端代理（EdgeOne Pages 函数 / Cloudflare Worker 持 token），或换 Formspree/Supabase 等方案。

### 其他待办
- 无 JS 兜底：`.reveal` 默认 opacity:0，JS 失败/禁用时整页空白 → 加 `.js` 类或 `<noscript>` 兜底。
- `favicon.png` 被引用但打包里没有 → 404，部署时补。
- 图片偏大：one.jpg ≈2MB，总计 ~2.3MB， rural 4G 慢 → 压缩到单张 <200KB。
- Google Fonts（Bagel Fat One/Fredoka 走 Google）国内常被墙 → 大标题可能退化成系统字体，建议自托管或换国内可达 CDN。
- `user-scalable=no,maximum-scale=1.0` 关缩放，可访问性差；建议移除。
- RSVP 链接 `https://wj.qq.com/s2/26799589/5ff2/` 需确认是真实问卷。
- 祝福墙/弹幕 rAF 与定时器常驻（离屏也跑），可加可见性暂停省电。
- 分享按钮桌面端复制链接无 toast 提示；地图 section 缺「复制地址」兜底（微信内常拦地图外链）。
